Hands-on

실습은 작게 시작합니다

처음부터 모든 권한을 열지 않습니다. 테스트 폴더에서 작은 작업만 해보고, 결과를 확인한 뒤 범위를 넓힙니다.

  • 1. 준비 노트북, 인터넷, 계정, 터미널, 테스트 폴더를 확인합니다.
  • 2. 연결 OpenAI, Claude, Gemini, OpenRouter 중 하나를 모델로 연결합니다.
  • 3. 첫 미션 중요한 파일이 없는 테스트 폴더에서 읽기 작업부터 실행합니다.
  • 4. 확인 결과가 맞는지 사람이 보고, 괜찮을 때만 권한을 넓힙니다.
Agent Examples

Hermes와 OpenClaw는 어디에 놓일까?

제품 이름보다 구조가 중요합니다. 둘 다 “AI 모델을 실제 작업 도구와 연결해 일하게 하는 에이전트 층”으로 설명합니다.

Hermes Agent는 메시지, 기억, 스킬, 도구 호출을 묶어 실제 업무를 처리하는 에이전트입니다.

OpenClaw는 여러 사람이 쉽게 만들고 쓸 수 있게 정리한 오픈형 에이전트 플랫폼으로 설명하면 됩니다.

비전공자에게는 “AI가 텔레그램, 파일, 웹, API와 연결되어 대신 일하는 구조”라고 말하는 것이 가장 쉽습니다.

Glossary

용어를 업무 언어로 바꾸기

설치와 실제 사용 중 자주 만나는 말입니다. 뜻보다 “어디서 쓰이고 무엇을 조심해야 하는지”부터 잡습니다.

  • LLM 글을 읽고 답하는 AI 두뇌입니다. GPT, Claude, Gemini 같은 모델이 여기에 들어갑니다.
  • 모델 AI 두뇌의 제품명입니다. 작업 성격에 따라 빠른 모델, 똑똑한 모델, 저렴한 모델을 고릅니다.
  • 프롬프트 AI에게 주는 업무지시서입니다. 목표, 조건, 금지사항, 결과 형식을 같이 적으면 좋습니다.
  • 에이전트 목표를 받고 계획을 세운 뒤 도구를 써서 일을 처리하는 AI 작업자입니다.
  • API 서비스끼리 대화하는 공식 통로입니다. 에이전트가 OpenAI, Telegram, GitHub 같은 서비스와 연결될 때 씁니다.
  • API 키 내 계정으로 서비스를 쓰게 해주는 비밀번호 같은 값입니다. 공개 저장소, 화면 공유, 단체방에 올리면 안 됩니다.
  • 토큰 로그인 권한을 증명하는 임시 출입증입니다. Telegram Bot Token, Access Token, Refresh Token처럼 이름이 붙습니다.
  • OAuth 인증 비밀번호를 직접 주지 않고 “이 앱에 이 권한만 허용”하는 로그인 방식입니다. Cloudflare, Google, GitHub 연동에서 자주 봅니다.
  • 권한 / Scope 앱이 할 수 있는 일의 범위입니다. 읽기, 쓰기, 관리자 권한을 구분해서 최소한만 열어야 합니다.
  • Tool / MCP AI가 파일, 브라우저, GitHub, DB 같은 외부 기능을 호출하는 방식입니다. 에이전트의 손발에 해당합니다.
  • Telegram Bot 텔레그램 메시지를 받아 에이전트로 전달하는 입구입니다. Bot Token을 연결해야 동작합니다.
  • Gateway 들어온 메시지를 어느 에이전트에게 보낼지 정하는 중간 관문입니다. 세션, 권한, 라우팅을 관리합니다.
  • Webhook 어떤 일이 생기면 정해진 주소로 자동 알림을 보내는 방식입니다. 메신저나 결제, GitHub 알림 연동에서 자주 나옵니다.
  • Endpoint API가 기다리는 정확한 주소입니다. 예를 들어 로그인 콜백 주소나 메시지 수신 주소가 여기에 해당합니다.
  • Docker / 컨테이너 프로그램을 독립된 상자 안에서 실행하는 방식입니다. 설치 충돌과 실수 피해를 줄입니다.
  • 환경변수 / .env API 키, 토큰, 서버 주소처럼 코드에 직접 쓰면 위험한 값을 따로 보관하는 설정 파일입니다.
  • CLI / 터미널 버튼 대신 글자로 명령을 입력하는 도구입니다. 설치, 실행, 로그 확인에 자주 씁니다.
  • 로그 프로그램이 남기는 작업 기록입니다. 안 될 때 원인을 찾는 첫 번째 단서입니다.
  • 세션 한 번 이어진 대화나 작업의 상태입니다. 같은 사용자인지, 이전 대화를 기억할지 판단할 때 씁니다.
  • 메모리 에이전트가 이전 대화, 사용자 취향, 작업 규칙을 기억하는 공간입니다. 잘못된 기억이 쌓이면 답도 흔들릴 수 있습니다.
  • 스킬 에이전트에게 추가하는 작업 능력입니다. 예를 들어 GitHub 배포, 이미지 생성, 문서 정리 같은 기능입니다.
  • Rate Limit / 사용량 제한 너무 많이 호출하면 잠시 막히는 제한입니다. 무료 계정이나 API 테스트에서 자주 만납니다.
  • Repository / Repo GitHub에서 코드와 파일을 보관하는 저장소입니다. Public이면 누구나 볼 수 있습니다.
  • 배포 내 컴퓨터의 파일을 NAS, GitHub Pages, Cloudflare 같은 외부 주소에서 볼 수 있게 올리는 작업입니다.
Safety

처음 설치할 때 안전 체크리스트

에이전트는 편리하지만 권한이 커질수록 위험도 커집니다. 처음에는 작게 열고 확인합니다.

  • API 키 비밀번호처럼 관리합니다. 화면 공유나 단체방에 노출하지 않습니다.
  • 테스트 폴더 처음에는 중요한 문서가 없는 폴더만 읽고 쓰게 합니다.
  • 위험 행동 금지 삭제, 결제, 메일 발송, 계정 설정 변경은 첫 실습에서 제외합니다.
