Card News 04

설치는 크게 열지 말고
작게 시작합니다

처음부터 모든 권한을 주면 위험합니다. 테스트 폴더와 작은 미션으로 확인한 뒤 범위를 넓힙니다.

  1. 1준비 계정, 터미널, 테스트 폴더, 인터넷 연결을 확인합니다.
  2. 2모델 연결 OpenAI, Claude, Gemini, OpenRouter 중 하나를 연결합니다.
  3. 3도구 연결 Telegram, GitHub, 파일, 웹 검색처럼 필요한 도구만 붙입니다.
  4. 4확인 결과가 맞는지 사람이 보고, 괜찮을 때만 권한을 넓힙니다.
Card News 05

설치 중 자주 만나는 용어

처음에는 뜻보다 “어디에 쓰이고 무엇을 조심해야 하는지”가 더 중요합니다.

LLM / 모델AI의 두뇌입니다. GPT, Claude, Gemini처럼 제품명이 붙습니다.
API서비스끼리 대화하는 공식 통로입니다. 연결 주소와 사용 규칙이 있습니다.
API 키내 계정으로 서비스를 쓰게 하는 비밀번호 같은 값입니다. 공개하면 안 됩니다.
토큰로그인 권한을 증명하는 임시 출입증입니다. Bot Token, Access Token이 대표적입니다.
OAuth 인증비밀번호 대신 “이 앱에 이 권한만 허용”하는 로그인 방식입니다.
Tool / MCPAI가 파일, 브라우저, GitHub, DB 같은 외부 기능을 호출하는 방식입니다.
Gateway메시지를 어느 에이전트에게 보낼지 정하는 중간 관문입니다.
Webhook이벤트가 생기면 정해진 주소로 자동 알림을 보내는 방식입니다.
Docker프로그램을 독립된 상자에서 실행해 설치 충돌과 실수 피해를 줄입니다.
.env / 환경변수API 키, 토큰, 서버 주소를 코드 밖에 따로 보관하는 설정입니다.
로그프로그램이 남기는 작업 기록입니다. 안 될 때 원인을 찾는 첫 단서입니다.
배포내 컴퓨터 파일을 NAS, GitHub Pages, Cloudflare 주소에서 보이게 올리는 일입니다.
Card News 06

에이전트는 편리하지만
권한이 커질수록 위험합니다

처음 설치할 때는 “최소 권한, 테스트 폴더, 사람 확인” 세 가지만 기억하면 됩니다.

처음 실습에서 피할 것

삭제, 결제, 메일 발송, 계정 설정 변경, 전체 디스크 접근은 제외합니다.

처음 실습에서 할 것

테스트 폴더 읽기, 간단한 요약, 웹 검색, 결과 확인처럼 되돌릴 수 있는 작업부터 시작합니다.

절대 공개하지 않을 것

API 키, Bot Token, OAuth 토큰, `.env` 파일은 화면 공유와 공개 저장소에 올리지 않습니다.
