AI

OpenAI

ChatGPT와 GPT 모델. 에이전트가 생각할 때 쓰는 대표적인 두뇌입니다.

두뇌

Claude

긴 글 읽기와 정리에 강한 모델 계열. 문서형 공부에 잘 맞습니다.

두뇌

Gemini

Google의 AI 모델. 검색과 업무 도구 생태계와 함께 이해하면 쉽습니다.

두뇌

OpenRouter

여러 모델을 한 통로에서 골라 쓰게 도와주는 연결 서비스입니다.

모델 통로

GitHub

코드와 프로젝트 파일을 보관하는 곳. 에이전트가 읽고 고칠 작업장입니다.

작업장

Docker

프로그램을 독립된 상자 안에서 실행합니다. 실습 환경을 분리합니다.

실행 상자

Cloudflare

내 서버나 웹앱을 외부에서 접속하게 연결할 때 쓰는 문지기입니다.

외부 연결

Cursor / VS Code

사람과 에이전트가 함께 파일을 읽고 고치는 편집 작업대입니다.

편집 도구
Hands-on

오늘 설치 실습 로드맵

명령어를 외우는 시간이 아니라, 내 컴퓨터 안에 작은 AI 작업 공간을 안전하게 만드는 시간입니다.

실습 순서

  • 0준비물 확인노트북, 인터넷, 계정, 터미널, 테스트 폴더
  • 1설치공식 문서 출처를 확인하고 복사합니다.
  • 2모델 연결OpenAI, Claude, Gemini, OpenRouter 중 하나를 연결합니다.
  • 3작은 미션테스트 폴더 읽기처럼 위험하지 않은 작업부터 시작합니다.
대시보드 안의 인포그래픽은 회의실 화이트보드처럼 보이게 했습니다.
Agent Examples

Hermes와 OpenClaw는 어디에 놓일까?

제품 이름보다 구조가 중요합니다. 둘 다 “AI 모델을 실제 작업 도구와 연결해 일하게 하는 에이전트 층”으로 설명합니다.

Hermes Agent

기억하고 스킬을 쌓는 에이전트

대화와 작업 경험을 메모리와 스킬로 쌓아 반복 업무를 더 잘 처리하도록 돕는 구조로 설명하기 좋습니다.

OpenClaw

내 컴퓨터/서버에서 움직이는 개인 자동화 에이전트

파일, 브라우저, 일정, 메신저와 연결되는 개인 비서형 에이전트 개념을 설명하기 좋습니다.

Glossary

용어를 업무 언어로 바꾸기

처음 듣는 말은 뜻보다 “어디에 쓰이는지”부터 잡습니다.

LLM

글을 읽고 답하는 AI 두뇌입니다. OpenAI, Claude, Gemini가 여기에 들어갑니다.

프롬프트

AI에게 주는 업무지시서입니다. 목표, 조건, 금지사항, 결과 형식을 담습니다.

에이전트

목표를 받고, 계획하고, 도구를 써서 일을 끝내려는 AI 작업자입니다.

도구 / MCP

AI가 파일, 브라우저, GitHub 같은 외부 기능을 연결해 쓰는 방식입니다.

API 키

AI 서비스를 내 계정으로 쓰게 해주는 비밀번호 같은 값입니다. 공개하면 안 됩니다.

Docker / 샌드박스

실습 환경을 독립된 상자 안에 넣어 내 컴퓨터를 덜 위험하게 만드는 장치입니다.

Safety

처음 설치할 때 안전 체크리스트

에이전트는 편리하지만 권한이 커질수록 위험도 커집니다. 처음에는 작게 열고 확인합니다.

API 키

비밀번호처럼 관리합니다. 화면 공유, 단체 채팅, 캡처 이미지에 노출하지 않습니다.

테스트 폴더

처음에는 중요한 문서가 없는 폴더만 읽고 쓰게 합니다.

위험 행동 금지

삭제, 결제, 메일 발송, 계정 설정 변경은 첫 실습에서 제외합니다.
